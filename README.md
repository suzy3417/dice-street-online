# 骰子街 · 在线桌游

依据用户提供的《骰子街》卡牌与规则图片制作，可在 [公开网页](https://suzy3417.github.io/dice-street-online/) 直接游玩。

## 游戏模式

| 人数 | 扩充 | 胜利条件 |
| --- | --- | --- |
| 四人 | 基础版 | 建成四座地标 |
| 四人 | 基础版＋百万富翁 | 建成四座地标 |
| 四人 | 基础版＋港口 | 建成六座地标 |
| 四人 | 基础版＋港口＋百万富翁 | 建成六座地标 |
| 五人 | 港口扩充 | 建成六座地标 |
| 五人 | 港口扩充＋百万富翁 | 建成六座地标 |

支持同设备轮流游玩与不同设备加入同一房间。扩充模式使用十种建筑的滚动市场。四人模式每种重要建筑备四张，五人模式每种备五张。房主选择模式，人数到齐后开始对局。对局中可切换查看每位玩家的建筑，并点击已建卡牌查看效果。

## 部署

网页由 GitHub Pages 从 `main` 分支根目录发布。游戏房间保存在 Supabase `king-5v5` 项目中，只使用 `dice_` 前缀的专用表和数据库函数；数据库定义见 `supabase/schema.sql`。`config.js` 只包含可公开的项目 URL 和 publishable key。不要把 service role key 放进前端。

本地运行：在项目目录执行 `python -m http.server 4173`，打开 http://localhost:4173 。

房间每约两秒同步。玩家身份由该浏览器保存的房间令牌识别；清除浏览器存储会失去该席位。当前采用朋友对局的客户端规则计算，不提供竞技级防作弊裁定。
